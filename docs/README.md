## 📖 About

This page contains a demo version of the AI Knowledge RAG System with a subset of the full knowledge base. The demo runs entirely in your browser with no backend required.

## 💡 Features

- **Instant Answers**: Search through AI/ML knowledge instantly
- **Smart Search**: Keyword-based intelligent search
- **Source Citations**: Every answer includes source information
- **No Backend Required**: Runs completely in the browser
- **Responsive Design**: Works on desktop and mobile
