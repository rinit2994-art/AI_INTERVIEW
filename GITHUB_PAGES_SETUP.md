## 📋 Step-by-Step Instructions to Enable GitHub Pages

### Step 1: Go to Your Repository on GitHub

1. Open your browser
2. Go to: `https://github.com/rinit2994-art/AI_INTERVIEW`
3. Make sure you're logged in to your GitHub account

### Step 2: Access Repository Settings

1. Click on the **"Settings"** tab (at the top of your repository page)
2. Look for **"Pages"** in the left sidebar
3. Click on **"Pages"**

### Step 3: Configure GitHub Pages

1. Under **"Source"** section:
   - Click the dropdown that says "None"
   - Select **"Deploy from a branch"**

2. Under **"Branch"** section:
   - Click the first dropdown and select: **`claude/testing-mi3ijx752vyq76rw-012MosigbdNbQTRaTK7twV1v`**
   - Click the second dropdown (folder) and select: **`/docs`**
   - Click **"Save"**

### Step 4: Wait for Deployment (1-2 minutes)

1. GitHub will start building your site
2. Refresh the Pages settings page after 1-2 minutes
3. You'll see a message like: "Your site is live at https://rinit2994-art.github.io/AI_INTERVIEW/"

### Step 5: Visit Your Live Website! 🎉

Your website will be available at:

```
https://rinit2994-art.github.io/AI_INTERVIEW/
```

## 🔍 Troubleshooting

### Issue: "404 - Site not found"
**Solution**: Wait 2-3 minutes after enabling. GitHub Pages takes time to build.

### Issue: "Cannot find /docs folder"
**Solution**: Make sure you selected the correct branch: `claude/testing-mi3ijx752vyq76rw-012MosigbdNbQTRaTK7twV1v`

### Issue: "Page shows old content"
**Solution**: Clear your browser cache or use Ctrl+F5 to hard refresh

### Issue: "Settings tab not visible"
**Solution**: Make sure you're logged in and have access to the repository
